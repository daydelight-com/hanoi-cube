# ハノイの塔アレンジ ルールブック

## 1. ゲーム概要

ハノイの塔の派生ゲーム。プレイヤーは円盤を塔に並べて「判定」ボタンを押す。並べた配置が「クリア可能な配置」であればポイントを獲得できる。制限時間1分の中でどれだけポイントを稼げるかを競う。

本家ハノイの塔が「決められた配置を速く解く」ゲームであるのに対し、本ゲームは「どの配置が解ける配置なのか、そしてどの配置が高得点なのか」という知識と、円盤を並べる操作速度を競う。

## 2. 用具

- 塔(棒): 3本。左からA・B・Cと呼ぶ。各塔に積める円盤は最大3枚。
- 円盤: サイズは「大」「中」「小」の3種類。各サイズ3枚ずつ、計9枚まで使用できる。同じサイズの円盤はゲーム全体に複数枚存在してよい。

## 3. 円盤の配置ルール(盤面の合法条件)

1つの塔の中では、次の条件を満たす積み方だけが認められる。

- 上から下に向かって円盤のサイズが大きくなること(上ほど小さい)。
- 同じ塔に同じサイズの円盤を2枚以上入れることはできない。

したがって1つの塔が取り得る状態は次の8通りに限られる(下から順に表記)。

> 空 / [小] / [中] / [大] / [中,小] / [大,小] / [大,中] / [大,中,小]

一番下の円盤が「大」である必要はない。[中,小]や[大,小]のような塔も合法である。盤面全体では 8×8×8 = 512通りの配置が存在する。

## 4. 円盤の移動ルール

「クリア可能かどうか」の判定は、以下の移動ルールに基づく。

- 1手で動かせるのは、いずれかの塔の一番上にある円盤1枚だけ。
- 移動先は、空の塔、または移動する円盤より大きい円盤が一番上にある塔に限る。
  - 同じサイズの円盤の上には置けない。
  - 移動先の塔がすでに3枚(満杯)の場合は置けない。

## 5. クリア可能な配置の定義

ある配置が「クリア可能」であるとは、上記の移動ルールに従った手順によって、次の2条件を同時に満たす盤面に到達できることをいう。

1. **左右反転**: 初期配置を**左右にひっくり返した配置**になっていること。A塔とC塔の中身が入れ替わり、B塔はそのまま。枚数だけでなく、どのサイズの円盤がどの塔にあるかまで一致させる必要がある。
2. **円盤の移動**: 少なくとも1枚の円盤が、初期状態とは別の塔に置かれていること。

条件2は**円盤を個体で数える**。同じサイズの円盤どうしを塔をまたいで入れ替えた場合、見た目(どのサイズがどの塔にあるか)は初期状態と同じでも、円盤自体は別の塔に移っているので条件2を満たす。

条件2が要るのは、初期配置がもともと左右対称のとき(例: `[大]/[中,小]/[大]`)に条件1が最初から成立してしまうため。この場合は円盤を実際に動かして戻ってくる必要があり、「0手でクリア」にはならない。

### クリア手順の例(最短3手)

```
初期        A:[大,中,小]  B:[大,中]    C:[大]
1手目 小をA→B    A:[大,中]    B:[大,中,小]  C:[大]
2手目 中をA→C    A:[大]       B:[大,中,小]  C:[大,中]
3手目 小をB→C    A:[大]       B:[大,中]    C:[大,中,小]  ← クリア
```

最終盤面 `[大]/[大,中]/[大,中,小]` は初期配置 `[大,中,小]/[大,中]/[大]` を左右にひっくり返した形になっている。

### 左右対称な配置のクリア例(最短3手)

初期配置が左右対称だと条件1は最初から成立しているので、条件2を満たすために円盤を動かして戻る。A塔の小を **a**、C塔の小を **c** と呼んで区別する。

```
初期          A:[大,中,a]  B:[大,中]    C:[大,中,c]
1手目 aをA→B   A:[大,中]    B:[大,中,a]  C:[大,中,c]
2手目 cをC→A   A:[大,中,c]  B:[大,中,a]  C:[大,中]
3手目 aをB→C   A:[大,中,c]  B:[大,中]    C:[大,中,a]  ← クリア
```

サイズだけを見ると初期と同じ盤面だが、a と c はどちらも初期とは別の塔にあるので条件2を満たす。

### クリア不可の例

`A:[大,中,小] B:[中,小] C:[大]` — Aの上の「小」はBの「小」にもCより先に置く場所がなく、有効な手がほとんど生まれない。目標の `[大]/[中,小]/[大,中,小]` には決して到達できない。

`A:[大] B:[大,中,小] C:[中]` — 枚数 (1,3,1) は最初から左右反転済みだが、条件1は**サイズまで**一致させることを求めるので、目標は `[中]/[大,中,小]/[大]`。両端の大と中を入れ替える手順は存在せずクリア不可。

`A:[大,中,小] B:[中,小] C:[大,中,小]` — 3塔とも一番上が「小」で空塔もないため、**合法な手が1手も存在しない**。左右対称な配置でもクリア不可になる。

## 6. 対戦モード(スコアアタック)のルール

### 進行

1. 制限時間は1分間。
2. プレイヤーは手元の円盤(大・中・小 各3枚)を自由に塔に並べる。並べる際は第3節の配置ルール(上ほど小さい・同サイズ不可・各塔3枚まで)を満たしていればよく、移動ルールには縛られない。
3. 配置ができたら「判定」ボタンを押す。
4. 判定後は円盤を並べ直して次の判定に進む。これを時間内に繰り返す。

### 得点

- 判定した配置が**クリア可能**であれば、次の得点を獲得する。

  **得点 = 盤面の円盤の総数 × その配置の最短クリア手数**

- クリア不可の配置を判定した場合、得点は入らない。減点もない。
- **同じ配置を2回以上判定しても、2回目以降は得点にならない。**
- **左右反転(鏡像)の配置は同じ配置とみなす。** 例えば `[大,中,小]/空/空` を判定済みなら、`空/空/[大,中,小]` も判定済み扱いとなり得点しない。
- **同じ配置かどうかは円盤のサイズと並びだけで判断する(個体は見ない)。** 第5節の条件2とは扱いが異なる。同じサイズの円盤を入れ替えただけの配置は、クリア判定こそ成立するが「同じ配置」なので2回目以降は得点にならない。

### 順位

- 1分間の合計得点が高いプレイヤーが上位。
- 同点の場合、**判定失敗(クリア不可配置の判定)の回数が少ない方**を上位とする。

## 7. 得点データ(参考)

- 全512配置のうち、クリア可能な配置は220通り。鏡像を同一視すると**得点対象は124クラス**。
- 最短手数の最大は**15手**(`[大]/[中,小]/[大]` — 左右対称で、両端の大を保ったまま中央の2枚を往復させる)。次点は7手が18配置。
- 総得点プールは1282点。1人のプレイヤーが1分間で現実的に到達できる上限は未計測(ルール変更後に要再見積もり)。
- 得点÷円盤数=最短手数なので、「並べる枚数あたりの得点効率」は最短手数がそのまま表す。少ない枚数で手数の多い配置ほど効率が良い。
