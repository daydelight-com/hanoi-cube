# S21 引き継ぎ: 確定アートワーク反映(箱・プレイマット・記録画面ファビコン)

ユーザー支給の画像素材を3D表示と記録画面に反映した。契約・サーバー側は無変更。

## 完了したこと

### 1. 素材の配置

- `frontend/public/textures/` を新設し6点を配置:
  - `cube_l.png` / `cube_l_logo.png`(大箱=緑、CUBEロゴ)
  - `cube_m.png` / `cube_m_logo.png`(中箱=橙、キャラクターロゴ)
  - `cube_s.png`(小箱=水色。**ロゴあり素材は支給されていない**)
  - `play_mat.png`(四隅マーカー・A/B/C塔枠・待機エリア込みの一枚絵。
    1191×842でA3横置き 420×297 と同縦横比)
- `cloud/record/public/favicon.png`(48×48)を追加し、`index.html` のリンクを
  PNGに差し替え。旧 `favicon.svg` は削除(他所からの参照なしをgrepで確認済み)。

### 2. テクスチャ生成の差し替え(`frontend/src/three/textures.ts`)

- `faceImageUrl(size, face)` を追加(純関数・テスト済み): ロゴ入りは**面1と面6**、
  面2〜5はロゴなし。小箱は全面 `cube_s.png`。
- `drawFaceCanvas` に baseImg 引数を追加。画像があれば面全体に描画し、その上に
  従来どおり AprilTag を重ねる。画像が読めなければ従来の色分け+ラベル描画に縮退
  (`SIZE_COLOR` はこの縮退用として存置。BoardScene のテクスチャ適用前の
  マテリアル初期色でも使用)。
- `buildMatTexture` は `play_mat.png` をマット全面に描画。読めなければ従来の
  仮描画(塔枠+待機エリア+四隅タグ合成)に縮退。マット画像には四隅マーカーが
  焼き込み済みのため、画像使用時はタグの重ね描きをしない。

### 3. テスト・検証

- `textures.test.ts` に `faceImageUrl` の3ケース(ロゴ面/非ロゴ面/小箱全面共通)を追加。
- `make check` 全パス(server 207 / frontend 113 / cloud 7)。
- ブラウザ実表示で確認: 6画像すべて HTTP 200、盤面に新テクスチャ描画、
  コンソールエラーなし。
