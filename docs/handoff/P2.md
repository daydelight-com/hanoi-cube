## 要判断(選んだデフォルト)

1. **待機スロットの間隔**: mock CV と同じ `X0 + slot * 42mm` で 9 スロットを一列に並べた。L 箱(75mm)は隣と重なるため、
   P3 で見た目が悪ければ `staging_slot_position()` だけを変えればよい(他は依存しない)。マット幅 420mm に 9 箱(計 465mm)は
   どの並びでも一列には収まらないので、2 段に分けるか重なりを許容するかは P3 で決める
2. **4 個目の拒否理由**: 塔に 3 個ある状態はどの箱を置いても同サイズ重複にも該当するが、`TOWER_FULL` を優先して返す
   (判定順: 個数 → 同サイズ → 大小)。失敗音は理由によらず同じなので影響なし
3. **同じ場所へのドロップ**(塔の top を同じ塔へ / 待機の箱を自スロットへ)は `PLACED`(no-op)として扱い配置音を鳴らす想定。
   無音にしたければ `DropOutcome.location == origin` で判別できる
4. `from_board` の同サイズ箱の番号割り当ては A→B→C 順(盤面文字列には箱 ID の情報が無いため)。実プレイでは `from_board` は使わず
   `initial()` から操作で積むので、往復テスト専用の規約
