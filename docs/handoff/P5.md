# P5 引き継ぎ: タイトル / ルール / リザルト + 効果音 + 日本語 UI

計画書 `docs/pyxel_app_development_plan.md` §4 の P5。タイトル・ルール(5 ページ)・リザルトを実装し、
全画面をクリックだけで接続。日本語 UI(JA/EN 切替)、自己ベスト(localStorage)、基調色 `#438532` の
パレット差し替え、効果音の調整を行った。既存コード(`server/` `frontend/` `cloud/` `docs/contracts/`)と
ランタイム(`pyxel_app/runtime/`)は変更していない。

## 完了したこと

### `pyxel_app/i18n.py`(仕様書 §3.6。Pyxel 非依存)

- `Messages`(frozen dataclass)の JA/EN 辞書。キー集合の一致は dataclass の構築時に強制され、
  空文字・フォントに無い文字はテストで検出する(下記)
- `RULE_PAGES`: 既存 `frontend/src/i18n/strings.ts` の 5 ページを文言そのまま流用(EN の `—`→`-`、`×`→`x` のみ ASCII 化)
- 言語状態はモジュールが 1 つ持つ(`current()` / `set_lang()` / `toggle()` / `msg()` / `rule_pages()`)。既定は日本語

### `pyxel_app/storage.py`(仕様書 §3.5、要判断 #6。Pyxel 非依存)

- `KeyValueStore` Protocol + 3 実装: ブラウザは Pyodide の `js` 経由で `window.localStorage`、
  ネイティブは `~/.hanoi_cube_pyxel.json`、テストは `MemoryStore`。ブラウザ側は `SafeStore` で包み、
  localStorage が例外を投げても(プライベートモード等)ゲームを止めず揮発に倒す
- `BestStore`: キー `hanoi_cube.best` に最高スコアのみ保存。`update(score)` が新記録なら True(同点は更新しない)。
  壊れた値・負値は 0 扱い。I/O 失敗は握りつぶしてゲームを止めない。`best_store()` がアプリ共有のシングルトン

## 要判断(選んだデフォルト)

1. **ルールは 5 ページ**。仕様書 §3.3 は「4 ページ構成」だが、文言の正である frontend `RULE_PAGES` が 5 ページ
   (「うごかしかた」を含む)のため、文言流用を優先して 5 ページとした
2. **自己ベストはスコアのみ保存**(盤面・日時は持たない)。キー `hanoi_cube.best`。同点は「しんきろく!」を出さない
3. **言語設定は永続化しない**(リロードで日本語に戻る)。ブースの言語切替も揮発なので合わせた
4. **パレット差し替えはスロット 3(GREEN)のみ**。`pyxel_app` 内で未使用だったため。基調色はボタン(スタート /
   はんてい / もういちど / とじる)、ルール見出し帯、リザルト枠、ロゴのシャドウに使用
5. **タイトルの「クリックで スタート」はプロンプト表示のみ**で、開始はスタートボタンのクリック(背景クリックでは
   開始しない。ルール / JA/EN ボタンとの誤爆を避けた)
6. **Esc はタイトルへの補助キー**(§3.1)としてゲーム / ルール / リザルトに実装。Pyxel 既定の quit_key が Esc のため
   `quit_key=KEY_NONE` に変更(終了は Q のまま。Web では quit は元々実質無効)
7. **HUD はラベルのみ日本語フォント 10px、数値は内蔵 4x6 のまま**(§3.6「内蔵フォントは HUD の数字など小さい表示に」)。
   ラベル幅が言語で変わるため位置は `text_width()` で毎フレーム計算
8. **MISS / ALREADY の文言は描画時に現在言語で解決**(`Feedback.text` は +N のみ使用)。`game_logic.py` は変更なし
9. **ネイティブの自己ベスト保存先はホームの `~/.hanoi_cube_pyxel.json`**(開発時の確認用。`.pyxapp` 内は読み取り専用のため)
