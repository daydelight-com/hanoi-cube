# S27 引き継ぎ: Pyxel Cube 版(ブラウザ単体で遊べる派生)の仕様書・設計書

本番(8/21-22)終了後の新規トラック。カメラ・AprilTag 付きの箱・iPad を使わず、
Pyxel の 3D 拡張「Pyxel Cube」(kitao/pyxel の `cube` ブランチ、未リリース)で盤面を描画し、
マウス/タッチのドラッグ&ドロップで遊べる版を GitHub Pages で公開する。
本セッションは**仕様書・設計書の作成まで**。実装は未着手。既存コードは一切変更していない。

## 完了したこと

### Pyxel Cube の調査と実機検証(リポジトリ外)

- cube ブランチ(`f731329`, 2026-08-12)は PyPI 未配布・公式 Web 実行経路(Web Launcher / CDN / app2html)
  のどれも対応していない(すべてリリース版 2.9.x の wheel を読む)。GitHub 上に第三者の利用例もゼロ。
- `pip install git+...@cube` は maturin が `python/pyxel/README.md`(`.gitignore` 対象、Makefile の `cp` 前提)を
  見つけられず失敗する。**ビルドは必ず Pyxel の Makefile 経由**。
- `~/workspace/pyxel-cube` に clone し、`make build-wasm` で
  `pyxel-3.0.0-cp311-abi3-emscripten_5_0_3_wasm32.whl` を生成。動作確認用リポジトリ
  `daydelight-com/pyxel-cube-example` を作り、GitHub Pages で cube のサンプル(c01)が動くことをユーザーが確認済み:
  https://daydelight-com.github.io/pyxel-cube-example/
- 必要なランタイム同梱物は `pyxel.js` / `pyxel.css` / `import_hook.py` / `images/`(7点)/ wheel の5種。
  `images/` または `import_hook.py` が欠けると真っ白のまま止まる(ロゴの `load` 待ち / 404)。

### 仕様書・設計書

- `docs/pyxel_app_specification.md`(新規、約560行)。既存 specification.md の派生として、
  スコープ / ディレクトリ構成 / 画面 / ドラッグ&ドロップ / 判定 / 設計 / 配信 / **セットアップ手順(Mac・Windows 併記)** /
  テスト / 非機能 / 要判断 10 件 / マイルストーン P1〜P4 を定義。
- 設計の骨子: `pyxel_app/` に閉じ、`server/app/core/`(judge / score / precompute)は import のみ。
  ランタイム wheel は `pyxel_app/runtime/` にコミットして固定(cube は API 策定中のため CDN 不使用)。
  アプリ開発者は Rust / Emscripten 不要(wheel は GitHub Release 配布)、フルツールチェーンはランタイム更新担当のみ。
- ユーザー決定事項: 配置先は hanoi-cube 内 `pyxel_app/`、ランキング(Firestore)は初回スコープ外。
