# S27 引き継ぎ: 接地自動校正の実装(高さの系統誤差をサーバー側で自動補正)

会期後(2026-08-22)の恒久対策。S24〜S26 で毎朝手作業になっていた「箱の高さの
系統誤差」(浮き・埋まり・接地判定のマージン侵食)を、サーバー側で自動推定・
補正する仕組みを実装した。ユーザーとの合意設計「四隅+高さ既知の箱で自己校正」を、
起動時だけでなく常時追従する形に一般化している。

## 完了したこと

### 背景(なぜ必要か)

マット四隅タグは全て高さ0の同一平面にあるため、キャリブレーションは高さ方向の
スケール(焦点距離)を自己検証できない。会期中の実測では接地箱の底面zが
-31〜+13mm ずれ、接地判定(許容25mm)の抜けや3D表示の埋まりの原因になった。
水平方向は四隅で拘束されるため常に正確だった。

### 実装

- `server/app/cv/ground_autocal.py`(新規): 純ロジック。
  「底面zが0近傍(|z|≤45mm)かつマット内の箱はマット面に静止している」を参照高さとし、
  最下クラスタ(幅20mm)の中央値を系統誤差とみなして、ゲイン0.02のEMAで補正量を
  更新(±30mmクランプ。代表値が上限超なら参照取り違えとみなし更新しない)。
  **誤差の推定は補正前の生の観測zに対して行う**(補正後の残誤差を追う方式は、
  再キャリブレーションで誤差の符号が反転した際に上限棄却と噛み合って更新不能に
  陥りうるため。Codexレビュー指摘で方式変更)。毎フレーム更新のため照明変化にも追従。
- `server/app/cv/tracker.py`: `elevated_box_ids()` を追加。確定盤面で段1以上にある
  箱のID(遮蔽保持中も維持)。土台が遮蔽され上の箱だけ見える+負の系統誤差、の
  組合せで積み箱を地面と誤学習しないよう、校正の参照から除外する(Codex指摘対応)。
- `server/app/cv/pipeline.py`: `_apply_ground_autocal` で推定→更新→補正の順に処理し、
  観測zから一様に引いてトラッカーへ渡す(相対値=積みギャップは不変)。補正量が初めて
  5mmを超えたら INFO ログ。`export/restore_calibration` に `ground_offset_mm` を追加
  (旧形式はキー無し=0で復元、復元値も±30mmクランプ)。解像度変更時は補正量も
  リセット(カメラ幾何が全て無効になるため)。
- `server/app/cv/worker.py`: 初回保存時は補正量がまだ≈0のため、収束後に
  `should_resave_calibration`(ドリフト2mm超かつ10秒間隔)でキャリブレーションを
  再保存し、次回起動へ引き継ぐ(Codex指摘対応)。`real.py` と合わせて
  `HANOI_CV_GROUND_AUTOCAL=0` の無効化経路あり(既定は有効)。README の環境変数表にも追記。
- `server/tests/test_ground_autocal.py`(新規16件): 純関数(窓・クラスタ・クランプ・
  収束・符号反転からの再収束・段1以上の除外)、パイプライン統合(合成シーンの幾何解決に
  バイアス-15mmを注入し約10秒相当で底面zが0近傍になること・無効化時は補正されないこと)、
  保存/復元・旧形式互換・復元クランプ・再保存判定。
  `make check` 全通過(server 224 / frontend 128 / cloud 12)。

### 運用への影響

- 来年の設営手順は「四隅を見せる+マット上に箱を1つ置く」だけで高さも自動で合う
  (置かなくてもプレイ開始後に接地箱が現れ次第、数秒で収束する)。
- S25 で入れた表示側の接地補正(frontend groundOffset)は残置。サーバー補正後は
  残誤差がほぼ0になるため表示補正は実質無効化されるが、二重補正の害はなく、
  サーバー補正を無効化した場合の保険になる。

## 契約からの逸脱・追加判断

- なし。cv-interface.md の `pos_mm`(底面中心)定義に対し、補正は定義への忠実度を
  上げる方向。エリア分類・積み判定の式は不変。
- 設計判断: 焦点距離そのものを補正する案(既知高さから逆算)は calibrate() の安定性に
  影響しうるため見送り、観測zへの一様オフセットとした。実測された誤差構造
  (ほぼ一様+位置依存±10mm弱)には十分で、残る位置依存分は判定許容の範囲内。

## 既知の問題

- 手持ちで箱をマット面近く(窓内)に静止させ続けると補正が引きずられる
  (ゲイン0.02で緩和。置き直せば数秒で再収束する)。
- 接地箱が1つもない状態が長時間続くと補正は更新停止(現状維持)する。
  積み箱は「トラッカーが段1以上と保持している」ことを根拠に除外するため、
  **土台の箱が一度もトラッカーに載らないまま上の箱だけが観測され続け、かつ負の
  系統誤差が大きい**場合に限り誤学習の余地が残る(接地箱が1つ見えれば最下クラスタが
  勝って回復する。ground_autocal.py docstring に明記)。
