## 要判断(選んだデフォルトと理由)

1. **ピクセルフォント**: アセット未確定のため `DotGothic16` →等幅系のフォールバックスタック+
   字間・グローで代替。フォント導入時は retro.css の `--retro-font` を差し替えるだけ
2. **せり上がり演出の実装**: コンテナを「最下位→…→1位」順に並べ、transition +
   inline style(translateY(100vh) → calc(45vh - 100%))で実装(CSS keyframes は終点が
   要素高に依存して書けないため)。静止時は1位が画面中央やや上・下位ほど上に並ぶ。
   時間は行数×1秒(2〜27秒クランプ)でサーバーのタイムアウトと同式
   (screens.md 行3の「S4で調整」は現行値のまま採用)
3. **mode_select のフォーカス端ループ**(screens.md 行5の「S4で調整」): サーバー実装
   (machine.py: 端でクランプ、ループなし)をそのまま採用。表示側は ctx.focus 追従のみ
