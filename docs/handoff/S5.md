## 要判断(選んだデフォルトと理由)

1. **GO! の表示**: サーバーが countdown:go と screen:game_play を同時送信するため、
   GO はクライアントで game_play 入場直後に0.8秒表示することにした(契約変更なしで仕様§5.6の
   見た目を満たす)。サーバー側で GO 表示時間を持たせたくなったら S6 以降で契約ごと再検討
2. **決定ボタンの無効表示**: 0文字時はディスプレイ側で減光表示のみ(押下無視はサーバーの
   ガードに任せる。screens.md 行24)
3. **QRの配色**: CRT調に合わせ濃緑×淡緑(#0a1a0a / #e8ffe0)。コントラストは高いが
   **実機スマホでの読み取り確認は未実施**(下記)
4. **iPad の name 完了**: iOS ソフトウェアキーボードの「完了」キーは submit を発火しない
   端末があるため、画面内に明示的な「かんりょう」ボタンを常設(form submit でも同送信)
