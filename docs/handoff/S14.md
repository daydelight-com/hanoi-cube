# S14 引き継ぎ: 全パターン記録(デモ用プレイ記録の生成と本番投入)

ユーザー依頼「全てのパターンを記録したプレイ記録を、得点が高い順・失敗は最後に」への対応。
記録画面(`cloud/record/`)で全512盤面の表示・最短手順再生を一度に確認できる合成データを作り、
本番 Firestore へ投入した。

  `judgements` に並べた `PlayRecord` を組み立てる。判定は `core/engine.judge` に委ね、
  本モジュールは**順序と体裁だけ**を担う(得点計算・重複判定を再実装していない)。
  - 並び順(依頼どおり): `scored` **124件を得点降順**(60→1。同点は円盤数昇順→正準キーの

    `unclearable` **292件を最後**(=失敗パターン)

  - `tower_box_ids` は A→B→C・下から上の順に `large-1` … を割り当てる代表割り当て

## 要判断として選んだデフォルト(CLAUDE.md 規則3)

1. **「全パターン」= 合法盤面512件すべて**(ユーザー確認済み)。鏡像も別カードとして残す
   ため、得点クラス124件のあとに `duplicate_mirror` 96件が並ぶ
2. **失敗 = `unclearable`**(クリア不可盤面)と解釈し末尾にまとめた。`duplicate_*` は
   0点だが「失敗」ではないため中間に置く(`fail_count` にも数えない=ルールブック§6)
3. **投入先は Firestore のみ**(ユーザー確認済み)。ローカルSQLite には入れていない
4. `duplicate_same` は出現しない(同じ盤面文字列を2回置かないため)。記録画面の
   `duplicate_same` 表示経路はこのデータでは確認できない
