## 要判断(選んだデフォルトと理由)

1. **面番号→箱の向きの対応**: cv-interface.md は「quat単位=面1が上」のみ規定、面2〜6は未規定
   (物理貼付も「どの面を面1にするかは自由」)。`faces.ts` を正として
   面1=+z(上) 面2=-y(手前) 面3=+x(右) 面4=+y(奥) 面5=-x(左) 面6=-z(底) と定義した。
   **実CV(S8)は同じ対応で quat を出すこと**(faces.test.ts が法線整合を検証)
2. **タグ貼付余白**: 面隅からのシール余白は未規定 → 3mm(textures.ts の `TAG_MARGIN_MM`)。
   実物の貼付と合わせるのは実CV統合時(S8)でよい(仮テクスチャの精度で十分)
3. **平滑化パラメータ**: λ=12/s。モックの離散ジャンプ(盤面一括セット)も補間で滑らかに見せる。
   実CVの連続ストリームでは体感調整の余地あり(smoothing.ts の定数のみで変更可)
